# Manufacturing Analytics Platform

A full-stack manufacturing analytics platform built using React, Express, Prisma, and PostgreSQL.

The application is designed to manage manufacturing facilities, production lines, machines, production batches, sensor readings, downtime events, and analytics dashboards.

---

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend

- Node.js
- Express.js
- TypeScript
- Prisma ORM

### Database

- PostgreSQL
